pdweb Display Information

1. What the browser reports

Chrome and Edge can list every attached display and its name with the Window Management API. The browser asks for permission first. It never reports the serial number or physical size.

2. Read the EDID with PowerShell (Windows)

The EDID is the identification block each monitor sends to the computer. It contains the manufacturer, model, serial number, manufacture date, and the physical size the pixel pitch is calculated from.

  1. Open Windows PowerShell from the Start menu. You do not need to run it as administrator.
  2. Copy the command below, paste it into PowerShell, and press Enter. It only reads the EDID of the displays connected now and copies it to the clipboard as hexadecimal text, one line per display. It changes nothing on the computer.
  3. Paste the result into the box below.
