pdweb

Read the display's EDID (Windows)

Every display sends Windows a short identification record, its EDID, holding the model, serial number and physical size. This command copies the EDID of each connected display so pdweb can read it. What this command does, at the bottom, explains it piece by piece.

  1. Open Windows PowerShell from the Start menu. It does not need to run as administrator.
  2. Copy the command, paste it into PowerShell and press Enter. Nothing is shown; the result goes to the clipboard.
  3. Paste the result into the box below.

      What this command does read-only, no administrator rights
      
It only reads. It needs no administrator rights, changes no settings or files, does not connect to
        the internet, and runs no other program or code. The result is decoded in this page; nothing is
        uploaded. Piece by piece:

      

        Get-CimInstance -Namespace root\wmi WmiMonitorID
        
Asks Windows for the displays connected right now. WmiMonitorID is the name Windows
          gives this list (Windows calls displays monitors). Each entry carries the display's device name.

        | % { … }
        
Runs the part in braces once for each display in the list. % is PowerShell's
          shorthand for ForEach-Object.

        $_.InstanceName -replace '_\d+$'
        
Takes that display's device name and removes the _0 at its end, which leaves the
          name of the registry key where Windows keeps the display's details.

        (Get-ItemProperty ('HKLM:\SYSTEM\CurrentControlSet\Enum\' + … + '\Device Parameters')).EDID
        
Reads the EDID value in that key, saved by Windows when the display was connected.
          Reading it needs no administrator rights.

        -join ( … | % { $_.ToString('X2') })
        
Writes each byte of the EDID as two hexadecimal characters and joins them into one line of text
          per display.

        | Set-Clipboard
        
Puts the text on the clipboard, ready to paste here.

      

      
Commands used in phishing usually download something (Invoke-WebRequest,
        iwr, a web address), run text as code (Invoke-Expression, iex),
        start other programs (Start-Process), or hide what they do (-EncodedCommand).
        This command has none of these. Your IT department can confirm this before you run it.

      

    

  






  
  

    
Display

    
The display under test. Its ID labels the lumResponse and uniformity exports and
      their filenames. Type an ID, or read one from the display.

    
    

      
      
      
    

    

      Details make, model, serial, manufacture date
      

        

        

        

        

      

      
Recorded in the reports as separate fields. Read EDID fills them in, or type them from
        the label on the display. The EDID gives the week of manufacture; the date is the Monday of that week.
        With the Display ID left empty, Set makes it from the model and serial.

      calculate by dividing the active area width in mm by the horizontal resolution.
