Instructions

Single readings from the connected photometer. Use this to spot check luminance, measure ambient illuminance, or confirm the instrument is working before a luminance response check.

Connecting

  • Needs a Chromium browser (Chrome or Edge) - WebHID is not available in Firefox or Safari.
  • Press Connect and pick the instrument in the browser dialog.
  • Connection process reads the instrument's own calibration out of its EEPROM. The Product and Serial fields fill in once that succeeds.
  • Unplugging the instrument drops the session. Press Connect again to recover.

Cover position

The diffuser cover decides what the instrument is able to measure, and the two are not interchangeable:

  • Cover off - emissive. Measures a light-emitting surface, reported as luminance in cd/m². Use it to characterize the display luminance response function or measure the display luminance uniformity.
  • Cover on - ambient. Measures light falling on the diffuser, reported as illuminance in lux. Use it to measure the ambient conditions.

Auto (default) reads the cover position and picks the matching quantity. Set the measurement quantity explicitly if you would rather be told when the cover is in the wrong place than have the unintended quantity reported.

Taking a reading

  • Single read - one measurement, averaged over the Averages setting.
  • Continuous - repeatedly measures until stopped.
  • Copy - the current reading, put on the clipboard.

What the numbers mean

  • luminance (cd/m²) - the measured luminance, after any Scale factor.
  • illuminance (lux) - the measured illuminance, after any Scale factor.
  • u', v' - CIE 1976 chromaticity coordinates. Distances in u', v' are roughly uniform perceptually.
  • x, y - the CIE 1931 chromaticity coordinates for the same measurement, shown for completeness.
  • XYZ - the underlying tristimulus values.
  • Diagnostics holds the raw sensor frequencies before the calibration matrix is applied. Worth a look if a reading seems wrong.

Advanced settings

  • Measurement mode - Adaptive starts in frequency mode and switches to period timing when the level is too low for frequency counting to be precise. Frequency only is faster but noisy at low luminance. Leave it on Adaptive unless you have a reason.
  • Averages - measurements combined per reading. Raising it cuts noise and costs time, roughly linearly; defaults to 2.
  • Scale factor - multiplicative correction factor for luminance/illuminance result. Used for a known correction against a reference instrument; defaults to 1.0.

Getting a trustworthy reading

  • Let the display warm up per manufacturer recommendations.
  • Seat the instrument flat against the surface so no stray light reaches the aperture, and keep its cable from pulling it off square.
  • Make measurements in the desired environment. For clinical compliance testing, the ambient conditions should match the typical environment.
  • Near black, the chromaticity is not meaningful for the human visual system. Measurements of u', v' below 5 cd/m² aren't useful for determining display compliance.

Links

  • A link can open a tool directly: pdweb.html?meter, ?lumresponse, ?uniformity or ?patterns.

Perform a luminance response conformance check on a display. The test measures how closely the display follows the DICOM Grayscale Standard Display Function, along with the AAPM Report No. 196 gray tracking metrics.

The patch is painted with CSS rgb(), so the browser and the operating system color-manage it to the installed display profile before it reaches the display. No web API exposes that transform, and nothing in this page can detect it. If the clinical viewing interface you are testing renders through a different path - its own calibration LUT, for example - then the digital driving levels measured here are not the ones that clinical viewer emits. Confirm the display profile and the clinical viewer's rendering path before treating these results as a conformance/calibration record.

Setting up

  • Ensure the cover is off.
  • Allow sufficient display warm up. Check the manufacturer's specifications for necessary time. If unavailable, use 20-30 minutes for LED backlights and 45-60 minutes for CCFL backlights.
  • Turn off anything that changes luminance on its own: ambient light sensors, automatic brightness, local dimming where it can be disabled, power saving, and screen blanking.
  • Put the display in the preset you intend to test (i.e., DICOM GSDF).
  • Set the ambient light level to match clinical usage. Measure the ambient contribution and enter it as Lamb (see below).
  • Optionally, set the Display in the Settings dock (bottom right). Its ID goes in the export header and the filename; Read EDID there fills in the model, serial number and manufacture date from the display itself. If left blank, it'll be blank in the export.

Collecting data

  • Choose 18, 52, or 256 point. The 18 point test lands on exactly the levels of the TG18-LN test pattern set (every 15 gray levels: DDL 0, 15, 30, ..., 255), which is also the same sampling AAPM Report No. 196 uses. The 52 and 256 point tests give a finer curve (at proportionally more time and typically with increased noise). AAPM Report No. 270 recommends using 52 points when available. Note: take care when using more points against the typical 10% and 20% criteria - the increase in data points reduces the "smoothing" gained with fewer points and tends to result in an apparent increase in non-conformance. The 10% and 20% thresholds were developed using the 18-point test and are not necessarily appropriate for data collection using more points.
  • Ext 18 and Ext 11 measure an external display - one connected to another workstation, e.g., a modality acquisition workstation. pdweb coordinates nothing in these modes: it simply takes a reading on a fixed interval while you adjust the gray level patch or pattern on the other display, and labels the readings with the gray levels you are supposed to be on. Everything after capture - analysis, charts, and all exports - is identical to a local data collection.
    • Ext 18 uses the TG18-LN levels. Ext 11 uses the eleven gray steps of the SMPTE pattern, 25.5 gray levels apart and rounded (DDL 0, 26, 51, 77, ..., 255).
    • Display the matching pattern on the external display before starting.
    • The data acquisition process gives you one interval to seat the probe on the DDL 0 (black) patch, then takes four readings there back to back without pausing - three background readings and the ramp's own DDL 0 point.
    • The stage shows which patch is next and counts down to the reading. Adjust while it counts, hold still once it says so. Set the pace with Move delay in Advanced settings.
    • The countdown starts when the previous reading finishes. A run therefore takes a little longer than the interval times the number of levels.
    • There is no way to redo a level. If you fall behind, Stop and start again - a reading taken between patches is indistinguishable from a real one in the numbers.
    • pdweb flags what it can: a level reading darker than the one below it, a level stuck to the luminance floor, and a run where the tab was in the background (which lets the browser throttle the countdown so it no longer matches real time).
  • Full screen fills the display with the luminance patch. This matters on OLED and on any display with local dimming, where the luminance patch area changes how hard the display is driven - a small patch on black does not measure the same as a full field. Leaving full screen mid-run stops the acquisition. For external readings, the setting is ignored.
  • In full screen the interface waits at Ready to measure. Position the photometer, then press Space or click Go. Esc cancels.
  • Every acquisition begins with three background readings at DDL 0.
  • Stop ends the run. A stopped or incomplete run keeps its points for export but produces no analysis.

Settings

  • Lamb - ambient luminance reflected off the display surface, in cd/m². It is added to every measured level to calculate the combined luminance L', which is used for the GSDF analysis. Measure it with the display powered off and the room in its typical setting, or take it from the display's documentation. Leaving it at 0 is generally incorrect and will overestimate the available contrast performance in the darkest regions.
  • Averages - number of measurements to average at each level.
  • Scale - multiplicative coefficient for the photometer. Leave at 1 unless you have a cross calibration reference or correction factor with another meter.
  • Chromaticity ref - the white point that Δu'v' is measured against. D65, D50, or a custom u', v' pair. This is an absolute reference and is separate from the AAPM Report No. 196 metrics, which compare the display's chromaticity against itself.
  • Color floor - Lower threshold for inclusion in the determination of Δu'v' and its chart. Applied to the measured luminance, not the combined luminance L', which matches how AAPM Report No. 196 makes its own exclusion. The count of levels actually used is reported. Most references use 5 cd/m². Below this level, the human visual system has a difficult time distinguishing between colors.
  • Move delay - seconds to advance the pattern on the external display measured in the Ext 18 and Ext 11 modes. It is measured from the end of one reading to the start of the next. It has no effect on the local-patch modes, where the page paints its own patch and the probe never moves.

Reading the results

  • L'min / L'max - Minimum and maximum combined luminances (include Lamb).
  • Luminance ratio - L'max/L'min.
  • Ambience ratio - Lamb/Lmin (n.b., denominator excludes Lamb).
  • Total JNDs - calculated total just-noticeable difference (JND) steps between L'min and L'max.
  • Mean JND/GL - mean JNDs per gray level, averaged over the whole grayscale.
  • Max JND/GL error - the largest error of any interval from the mean, with the interval it happened on. This is one measure of DICOM GSDF conformance.
  • Max dLL/JND error - the largest departure from the GSDF target contrast, with the interval it happened on. This is another measure of DICOM GSDF conformance. It's typically similar to Max JND/GL error.
  • Max ref Δu'v' - the greatest Euclidean distance in the CIE 1976 u', v' chromaticity diagram from the selected reference white.

AAPM Report No. 196 gray tracking

From AAPM Report No. 196. These four metrics measure how consistent the color of the gray ramp is, referenced to the display's own white point rather than to an absolute reference white point. This is different from Δu'v' above which is in reference to an absolute reference (e.g., D65).

  • 𝒯1 - mean Δu'v' between each level and full white. A low value means the display's chromaticity is consistent over the full gray scale.
  • 𝒯1max - the largest 𝒯1 and its level. Used to identify largest color difference from full white.
  • 𝒯2 - mean Δu'v' between consecutive levels. A low value means the display's chromaticity changes smoothly (even if it drifts).
  • 𝒯2max - the largest 𝒯2 and its levels. Used to identify largest point-to-point change in chromaticity.

Levels dimmer than max(5 cd/m², 1% of full white) are discarded first, as the report specifies, and the number kept is reported. AAPM Report No. 196 sets no pass/fail limits; it notes only that AAPM TG18 uses 0.01 as a spatial uniformity limit. Comparing 𝒯2 across acquisitions is only meaningful at equal sampling - finer steps mean smaller gaps between neighbors, so a 52 or 256 point run produces a smaller 𝒯2 than an 18 point run of the same display.

Charts

  • JND / GL by gray level - each point is one interval. The global mean sits at the vertical center with the ±10% and ±20% bands around it.
  • dL/L per JND vs GSDF target - measured contrast per JND against the target GSDF curve. ±10% and ±20% bands sit around the target curve.
  • Chromaticity u'v' - the ramp's path in u'v' centered on the reference, with rings at Δu'v' 0.01 and 0.02. Edge bars mark the directions of the primaries.

Exporting

  • cLR - the pacsDisplay luminance response format, including the three background readings as its stabilization block.
  • JSON - the full acquisition: every point, the background readings, the capture settings, the analysis summary, and a record of the browser and screen it was captured on.
  • Copy data - the measurement table, tab separated, for pasting into a spreadsheet.
  • Copy analysis - the conformance summary and gray tracking metrics, tab separated, for pasting into a report. Any warnings travel with the numbers.
  • Copy and PNG on each chart - that chart as an image, to the clipboard or to a file. The image is redrawn for a white page and carries the chart's title, legend, and note, so it can go straight into a report.
  • Import reloads an exported JSON with no instrument attached, and Re-analyze reruns the analysis against the current Lamb, color floor, and white point reference.

Measure luminance uniformity across the face of a display. Nine positions are measured at each of one, three, or eighteen gray levels and reported as LUDM and MLD, the uniformity metrics of AAPM Report No. 270 and Online Report No. 3 (TG18).

The pattern is painted with CSS rgb(), so the browser and the operating system color-manage it to the installed display profile before it reaches the display. No web API exposes that transform, and nothing in this page can detect it. Uniformity is a ratio between positions measured at the same driving level, so it is far less sensitive to that path than a luminance response check - but the gray levels named here are still not necessarily the ones the display receives.

Setting up

  • Ensure the cover is off.
  • Allow sufficient display warm up. Check the manufacturer's specifications for necessary time. If unavailable, use 20-30 minutes for LED backlights and 45-60 minutes for CCFL backlights.
  • Turn off anything that changes luminance on its own: ambient light sensors, automatic brightness, local dimming where it can be disabled, power saving, and screen blanking. Local dimming matters more here than anywhere else in this page - it is designed to make the display non-uniform.
  • Measure the ambient contribution and enter it as Lamb. It is added to every reading inside the LUDM and MLD calculation. The matrices, the exports and the Luni file all report measured luminance L.
  • Optionally, set the Display in the Settings dock (bottom right). Its ID goes in the export header and the filename, with the model, serial number, and manufacture date when they are set.

Collecting data

  • Choose 1, 3, or 18 level. These are gray level counts, not point counts - all nine positions are measured either way.
    • 1 level measures at DDL 210 (about the 80% level).
    • 3 level measures at DDL 30, 120 and 210 (about 10%, 50% and 80%). AAPM Report No. 270 recommends this set for routine testing.
    • 18 level measures every 15 gray levels, DDL 0 through 255 - the TG18-LN levels.
  • The probe is seated once per position and the whole gray ladder is measured without moving it. Nine seatings, whichever level count you choose. The target ring shows where to put the probe next and the countdown gives you time to get there; the ring disappears when measurement starts.
  • Positions are measured in a serpentine order - left to right across the top row, right to left across the middle, left to right across the bottom - so the probe travels the shortest path. Everything you read afterwards is in normal reading order regardless: UL UC UR / CL CC CR / LL LC LR.
  • Ext measures an external display - one connected to another workstation. pdweb coordinates nothing: it counts down while you move the probe to each of the nine positions on a pattern the other machine is displaying, and takes one reading at each. Display a uniform pattern there before starting. Full screen and full window settings are ignored.
  • Stop abandons the run. There is no way to redo a position, and a partial run is not analyzed - a missing position shifts the median and therefore every LUDM.

Field: single cell or full field

  • Single cell (default) lights only the ninth of the screen under the probe and keeps the other eight black. The lit area stays the same size all run, so the display is loaded the same way at every position, and results compare directly with other tools that measure uniformity a patch at a time.
  • Full field lights the whole screen at the gray level under test, which is how the TG18-UN patterns are defined - UNL10 and UNL80 correspond closely to the 3 level set's DDL 30 and 210. On an OLED or a locally dimmed display this reads quite differently from single cell, because the display drives a full white field far harder than one ninth of one.
  • Neither choice changes the sequence, the metrics, or the file format, and the mode used is recorded with the run. Note that at DDL 0 in single cell the screen is entirely black and the status line at the bottom edge is the only thing that will be lit.

Presentation: full screen or full window

  • Full screen uses the browser's full screen mode, so the nine cells are exact thirds of the physical display. This is the one to use for a whole-display measurement. Leaving full screen mid-run stops the run.
  • Full window fills the browser window instead. Use it when full screen is unavailable, or when you want to measure a defined area different than the whole display - size the browser window to the area, and the nine cells divide that. Esc leaves it.
  • Either way the run waits for Space or Go before the first measurement.

Reading the results

  • LUDM - luminance uniformity deviation from the median. The largest deviation of any of the nine positions from their median, as a percentage of that median: max |L' - median| / median x 100.
  • MLD - maximum luminance deviation, the spread between the brightest and darkest of the nine: 200 (L'max - L'min) / (L'max + L'min).
  • Both use L' = L + Lamb and are computed separately at each gray level. The summary reports the worst of each and the level it occurred at.
  • Max Δu'v' is the largest chromaticity distance of any position from the mean of the nine - color uniformity, which the luminance metrics say nothing about. Positions dimmer than the color floor are excluded, because u'v' is mostly noise there.
  • No acceptance limits are applied to any of it. They differ by display class and by which guidance a site follows.

The deviation map

  • Nine numbers tell you how much a display varies but not what shape the variation has - a left-to-right backlight gradient and one dim corner can produce the same LUDM. The map interpolates between the nine positions so the shape is visible directly.
  • It shows deviation from the median at one gray level; choose the level with the selector. It opens on the level with the worst LUDM.
  • Scale defaults to Auto, which fits the color range to this run's own largest deviation. That is what makes a small gradient visible at all, and it also means a good display fills the palette exactly as dramatically as a bad one. The colors show shape, not severity, and are not comparable between acquisitions. Use a fixed scale to compare displays by eye; use the numbers to judge either.

Exporting

  • Luni - the pacsDisplay uniformity text format: a commented header followed by a 3x3 matrix per gray level, so results drop into an existing workflow.
  • JSON - the full acquisition: every reading, the capture settings, the analysis summary, and a record of the browser and screen it was captured on.
  • Copy data - the readings, tab separated, one row per position and gray level, for pasting into a spreadsheet.
  • Copy analysis - the summary metrics and the per-level matrices, tab separated.
  • Copy plot and PNG on the map - the map as an image, redrawn for a white page.
  • Import reloads an exported JSON with no instrument attached, and Re-analyze reruns the metrics against the current Lamb and color floor.

Visual test patterns for display QC. They need no instrument and run in any current browser, including those without WebHID.

Opening a pattern

  • Pick a pattern. It opens over the whole window, and in full screen if Open full screen is checked.
  • The controls sit in the top corners: ? or H explains the open pattern, ⟲ or R resets it (zoom and pan, or the settings it opened with), ⛶ toggles full screen, and ✕ or Esc closes it. In full screen the first Esc leaves full screen and the second closes the pattern.
  • A pattern can be opened directly from a link: pdweb.html?pattern=grays&gray=128. Each pattern's help lists the parameters it accepts.

Pixels

  • Patterns are drawn in the display's own pixels. Bar and line-pair periods (1, 2, 4, 6 px) land on physical pixels at any operating system scaling, and pixel sizes such as the scan box are physical pixels, too.
  • That needs the canvas size in exact device pixels. A browser that cannot report it at a fractional scaling (125%, 150%) gets a notice when TG270-pQC, TG270-sQC, TG18-OIQ, or the ambient test opens; browser zoom at 100% and display scaling at 100% or 200% avoid it.
  • macOS: use the display's default resolution. The "scaled" resolutions resample the whole screen after the browser has drawn it, which no web page can detect or undo.
  • The display calibration (pixel pitch) setting sizes the interface and the measurement patch. It does not affect the patterns.
  • As with the measurement modes, the browser and operating system color-manage what is drawn. Evaluate patterns on the display profile and rendering path you intend to test.

Designs

TG270-pQC and TG270-sQC follow AAPM Report No. 270; TG18-OIQ follows AAPM TG18 (Online Report No. 3). They are redrawn from the published descriptions and scaled to the window; they are not the AAPM image files.

Comprehensive visual evaluation of display performance, following AAPM Report No. 270. Based on the TG18-PQC design.

Features

  • 18 horizontal gray bars, 0 to 255 in steps of 15.
  • Modulation columns. Left: horizontal modulation at 18, 12, 6, and 4 pixel periods; right: vertical modulation at 4, 6, 12, and 18 pixels. Outer columns are 8 gray levels of contrast, inner columns 2.
  • Line pairs in the top and bottom bars at 2, 4 and 6 pixel periods, high contrast (0/128 top, 128/255 bottom), for spatial resolution.
  • Side ramps, 0 to 255 full height, each with a center strip carrying a ±3 gray level sinusoid (periods 4π ≈ 12.6 px left, 3π ≈ 9.4 px right), for gradient reproduction.

Use

On a DICOM-conformant display, each frequency/contrast pair should be equally visible at every gray level. The visibility between different frequencies may vary. The modulation within the grayscale ramps should appear uniform at all levels. The high-contrast line pairs at the top and bottom should appear crisp.

Controls

  • Drag to pan; wheel to zoom (1x to 10x); ⟲ or R resets. Resizing the window also resets. Modulation and line-pair periods are fixed in display pixels and do not change with zoom.

Access the EDID (Extended Display Identification Data)

Every connected display sends the workstation an identification record, its EDID, holding the model, serial number, physical size, manufacturing date, and other details. This command copies the EDID so pdweb can read it. Explain this command, at the bottom, describes the process in detail.

  1. Open Windows PowerShell from the Start menu.
  2. Copy the command, paste it into PowerShell and press Enter. Nothing is shown; the result goes right to the clipboard.
  3. Paste the result (a bunch of hexadecimal characters) into the box below.

      

      
Result

      
      
The EDID of any display in hexadecimal also works here, for example from another EDID tool or,
        on Linux, from cat /sys/class/drm/*/edid | xxd -p. Base64 works too, one display per line.

      

      

      

        
        
      


      

      Explain this command
      
It only reads. It needs no administrator rights, changes no settings or files, does not connect to
        the internet, and runs no other program or code. The result is decoded in this page; nothing is
        uploaded. Each piece:

      

        Get-CimInstance -Namespace root\wmi WmiMonitorID
        
Asks Windows for the displays connected right now. WmiMonitorID is the name Windows
          gives this list. Each entry carries the display's device name.

        | % { … }
        
Runs the part in braces once for each display in the list. % is PowerShell's
          shorthand for ForEach-Object.

        $_.InstanceName -replace '_\d+$'
        
Takes that display's device name and removes the _0 at its end, which leaves the
          name of the registry key where Windows keeps the display's details.

        (Get-ItemProperty ('HKLM:\SYSTEM\CurrentControlSet\Enum\' + … + '\Device Parameters')).EDID
        
Reads the EDID value in that key, saved by Windows when the display was connected.
          Reading it needs no administrator rights.

        -join ( … | % { $_.ToString('X2') })
        
Writes each byte of the EDID as two hexadecimal characters and joins them into one line of text
          per display.

        | Set-Clipboard
        
Puts the text on the clipboard, ready to paste here.

      true size of the measurement patch (should be 10 cm). Check the display specifications or
      calculate by dividing the active area width in mm by the horizontal resolution.
